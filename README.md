# Terminal Quest 🐧

Jogo educativo para aprender o terminal Linux do zero, com missões, um terminal simulado e o pinguim Tux como professor.

## Como jogar
Abra o site e digite os comandos no terminal do jogo. Tudo é uma simulação: nenhum comando é executado no seu computador de verdade.

## O que tem no jogo
- Campanha em capítulos, de pwd e ls até grep, pipes e permissões
- Desafios que combinam vários comandos
- Tux, que explica seus erros e dá dicas em 4 níveis
- Central de Ajuda com busca de comandos
- Escolha de distro: Zorin OS, Ubuntu, Fedora e Arch/CachyOS
- Música chiptune e efeitos sonoros
- Progresso salvo no navegador

## Como rodar localmente
Baixe o arquivo `index.html` e abra no navegador. Não precisa instalar nada.
